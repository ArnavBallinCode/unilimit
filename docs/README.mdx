# UniLimit documentation

Start with the [two-minute runnable example](/README#try-it-in-two-minutes).
New to backend development? Read [the concepts guide](/docs/concepts) first.

## Build your application

- [FastAPI](/docs/fastapi/quickstart): dependencies, middleware, and HTTP responses.
- [Django](/docs/django/quickstart): settings, middleware, and view decorators.
- [Django REST Framework](/docs/drf/quickstart): authenticated throttle scopes.
- [WebSockets](/docs/fastapi/websockets): message budgets and connection leases.
- [Migration](/docs/migration): from SlowAPI ([guide](/docs/fastapi/migrating-from-slowapi)),
  django-ratelimit ([guide](/docs/django/migrating-from-django-ratelimit)), DRF and others.
- Starlette without FastAPI: install `"unilimit[starlette]"` and use
  `unilimit.integrations.starlette` (middleware and WebSocket limits).

Engineered For Scale

Why developers are switching from legacy limiters

Traditional Python libraries force you to juggle disparate, unmaintained libraries with blocking I/O and leaky atomicity. UniLimit replaces them all.

Atomic Multi-Tier Batches

Evaluate 10/sec, 100/min, and 10,000/day in a single Redis EVALSHA. If any limit trips, zero counters increment. No over-admit bugs, no compensating decrements.

Zero Raw Identities in Storage

Privacy by design. Client IPs, auth tokens, and usernames are strictly hashed using keyed HMAC/BLAKE2b before hitting Redis keys. GDPR & SOC-2 compliance out of the box.

Async & Sync Native

Core policy is purely sans-I/O. Async routes use native non-blocking redis.asyncio. Sync views use standard thread-safe Redis. No event-loop poisoning.

Cluster & Sentinel Failover

Automatic hash-tagging ({user:123}) guarantees multi-rate batches route to the exact same Redis cluster shard, eliminating CROSSSLOT keys errors.

Safe In-Memory Outage Fallback

If Redis goes down, UniLimit can seamlessly degrade to local process-isolated sliding windows. Your service stays protected against cascading traffic surges.

IETF Headers & Telemetry

Emits modern standard RateLimit-* headers and classic X-RateLimit-*. Built-in hooks for Prometheus and OpenTelemetry with zero overhead.

main.py (FastAPI) 
from fastapi import Depends, FastAPI
from unilimit import Limiter, Rule
from unilimit.integrations.fastapi import RateLimit, setup

# 1. Initialize Limiter with global application rules
limiter = Limiter.from_url(
    "redis://localhost:6379/0",
    global_rules=[Rule("site", "100/minute")],
)

app = FastAPI()
setup(app, limiter)

# 2. Endpoint-level multi-tier rate limiting
@app.get("/search", dependencies=[Depends(RateLimit("search", rate="5/second;60/minute"))])
async def search(q: str = ""):
    return {"results": f"Searching for {q}"}

# 3. Synchronous endpoints work natively without event-loop overhead
@app.get("/status")
def status():
    return {"status": "operational"}

from fastapi import FastAPI, WebSocket, WebSocketDisconnect, Depends
from unilimit import Limiter
from unilimit.integrations.fastapi import WebSocketRateLimit, setup

limiter = Limiter.from_url("redis://localhost:6379/0")
app = FastAPI()
setup(app, limiter)

connect_limit = WebSocketRateLimit("ws-handshake", rate="10/minute")
msg_limit = WebSocketRateLimit("ws-messages", rate="5/second;60/minute")

@app.websocket("/live-feed", dependencies=[Depends(connect_limit)])
async def feed(ws: WebSocket):
    await ws.accept()
    try:
        while True:
            data = await ws.receive_text()
            decision = await msg_limit.consume(ws)
            if not decision.allowed:
                await ws.send_json({"error": "slow_down", "retry_after": decision.retry_after})
                continue
            await ws.send_text(f"Processed: {data}")
    except WebSocketDisconnect:
        pass
from unilimit import Limiter, Rule

# Pure Python, framework-agnostic limiter
limiter = Limiter.from_url("redis://localhost:6379/0")

# Atomic multi-tier evaluation
decision = limiter.consume(
    "tenant_42", 
    [Rule("sec", "10/s"), Rule("day", "5000/d")]
)

if decision.allowed:
    print(f"Allowed! {decision.remaining} requests remaining")
else:
    print(f"Blocked! Retry after {decision.retry_after} seconds")

Request Lifecycle

How a request flows through UniLimit

STEP 01

Request Inbound

FastAPI dependency, Django middleware, or pure Python limiter intercepts the incoming request context.

STEP 02

Sans-I/O Policy

Identities are cryptographically salted & hashed. Multi-tier rules and cluster hash-tags are generated in memory.

STEP 03

Atomic Redis Lua

A single EVALSHA executes in Redis with server-side microsecond precision. All tiers commit together or reject.

STEP 04

Decision & Headers

Standard RateLimit-* headers are injected. If rejected, a 429 response with exact Retry-After is returned.

Installation & Requirements

1. Choose your installation bundle

Install core with optional framework and Redis drivers:

# For FastAPI with Redis:
pip install "unilimit[fastapi,redis]"

# For Django with Redis:
pip install "unilimit[django,redis]"

# For Core only (zero runtime dependencies, in-memory):
pip install unilimit

2. Supported Algorithms

UniLimit ships with mathematically proven, battle-tested algorithms verified by Hypothesis property fuzzing:

  • Token Bucket Smooth burst tolerance with steady replenishment.
  • Sliding Window Weighted sliding estimation with zero boundary spikes.
  • Fixed Window Lean integer counter for high-volume coarse limits.
